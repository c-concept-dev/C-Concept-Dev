### Point d’architecture clarifié

Une première tentative a supprimé la publication `globalThis.JMMJSActivityProgressionCore` afin d’interpréter au sens strict « zéro effet au chargement ».

L’inspection de `src/core/activity-progression-persistence.js` a montré que l’adaptateur D103A2 existant utilise explicitement cette API comme dépendance par défaut :

```js
core = globalThis.JMMJSActivityProgressionCore
```

La suppression aurait donc créé une régression de l’intégration existante.

Cette tentative a été annulée immédiatement.

Décision : la publication d’un objet API gelé est conservée comme **surface d’intégration technique**. Elle ne constitue pas une règle métier, une persistance ou une mutation de données utilisateur. Le test contrôle désormais qu’aucun autre état global n’est créé au chargement.
