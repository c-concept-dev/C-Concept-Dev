Traducteur EPUB / PDF → Français

Déposez un document dans sa langue d'origine : il vous revient en français, reconstruit au format EPUB — avec, en option, un export PDF.

1 Type de document

Roman / Document
EPUB, PDF, TXT, HTML — traduction de texte classique.
Bande dessinée / Manga
CBZ, ZIP d'images, ou images seules — OCR + traduction + réinsertion dans l'image.

Le mode YOLO télécharge un modèle de détection entraîné spécifiquement sur des bulles de BD/manga (109 Mo, une seule fois, mis en cache par le navigateur). Il détecte d'abord chaque bulle précisément, puis lit le texte dedans — normalement plus fiable que le regroupement automatique, mais plus lent à démarrer. Licence du modèle : GPL-3.0.

Le sens de lecture n'affecte que l'ordre des pages dans le fichier de sortie, pas le contenu. La détection de bulles est approximative : l'OCR groupe le texte par blocs proches, puis chaque bloc est recouvert d'un cadre et remplacé par le texte français. Sur des pages très denses ou des onomatopées stylisées, attendez-vous à des ratés.

3 Connexion à Claude

Mode Artifact claude.ai
Fonctionne directement si ce fichier est ouvert comme artifact dans une conversation Claude. Aucune clé requise.
Mode Proxy personnel
Pour un usage hors claude.ai, en local. Utilise votre Worker Cloudflare (ex. clone-proxy) comme relais vers l'API Claude.
Clé API directe
Collez votre clé Anthropic ici. Elle reste uniquement en mémoire dans l'onglet, jamais enregistrée sur disque, et disparaît quand vous fermez le fichier.

Votre proxy doit accepter un POST JSON {model, max_tokens, system, messages} et renvoyer une réponse au format standard de l'API Anthropic /v1/messages (champ content[].text). C'est déjà le contrat que suit votre Worker clone-proxy pour vos autres outils.

La clé n'est stockée que dans une variable JavaScript en mémoire vive, jamais dans le localStorage ni sur disque. Elle est perdue dès que vous rechargez ou fermez cette page — vous devrez la recoller à chaque session. Comme la clé transite dans ce même navigateur, gardez ce fichier HTML pour votre usage personnel uniquement.

4 Réglages

Le document est découpé en segments d'environ 2000 caractères pour respecter les limites de sortie de l'API. Le nombre de requêtes dépend donc de la longueur du texte — pour un roman entier, prévoyez plusieurs dizaines d'appels et quelques minutes. Jusqu'à 3 groupes de segments sont traduits en parallèle pour accélérer le traitement.

Pour un EPUB, chaque fichier du livre = un chapitre. Indiquez un nombre pour traiter seulement les N prochains chapitres non encore traduits, puis relancez plus tard dans le même onglet pour continuer là où vous vous êtes arrêté(e).
