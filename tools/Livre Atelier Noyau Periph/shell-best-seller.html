⚙ Configuration mode manuel — créer les Projects claude.ai (une fois pour toutes)

Pour éviter de coller le prompt système (~120 KB) à chaque appel, crée des Projects claude.ai avec leurs custom instructions pré-remplies. Le shell ne te demandera plus que le user prompt (court, lisible) qu'il faudra coller dans le Project correspondant.

Tu peux aussi rester en mode "Complet" qui inclut le system dans chaque copier-coller — c'est plus lourd mais ne nécessite aucune préparation.
