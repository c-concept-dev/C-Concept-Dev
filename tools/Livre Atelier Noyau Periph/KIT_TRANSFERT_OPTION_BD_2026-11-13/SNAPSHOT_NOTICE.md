# Nature de l’instantané

Le dossier `snapshot/` contient uniquement les quatre fichiers essentiels qui
ont servi à établir le cahier des charges et l’architecture de l’option BD :

- le noyau Auteur ;
- le noyau Éditeur ;
- le shell Biographie ;
- la recette d’intégration existante.

Cet instantané permet à une nouvelle conversation de comprendre rapidement le
point de départ, même si elle reçoit seulement l’archive du kit.

Il ne constitue ni une copie complète du dépôt, ni un historique Git, ni une
version livrable. Le dépôt situé à l’adresse suivante reste la source canonique :

`/Users/christophebonnet/Documents/GitHub/C-Concept-Dev/tools/Livre Atelier Noyau Periph`

Avant toute modification, comparer les fichiers de l’instantané avec ceux du
dépôt, puis travailler dans le dépôt. Ne jamais remplacer les fichiers du dépôt
par ceux de l’instantané sans vérification.
