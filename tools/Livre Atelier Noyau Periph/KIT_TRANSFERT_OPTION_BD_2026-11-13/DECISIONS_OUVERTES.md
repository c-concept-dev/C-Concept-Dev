# Décisions ouvertes

À trancher avant ou pendant le pilote :

1. Nom public : « Atelier BD », « Livre de Vie illustré » ou « Roman graphique » ?
2. Format pilote : A4, album 21 × 29,7 cm, carré ou format numérique vertical ?
3. Style pilote : ligne claire douce, roman graphique réaliste, aquarelle ou autre ?
4. Le pilote part-il d’un chapitre fictif créé pour les tests ou d’un chapitre réel autorisé ?
5. Le sujet doit-il valider chaque case ou seulement la bible, le storyboard et les planches ?
6. Mode initial : manuel ChatGPT uniquement, ou worker API dès le pilote ?
7. Les références photographiques sont-elles embarquées dans le projet ou conservées dans un dossier local séparé ?
8. Format de projet final : JSON avec fichiers adjacents ou archive ZIP renommée `.ldvbd` ?
9. Nombre maximal de variantes conservées par case ?
10. Faut-il un mode « visages non réalistes » pour les sujets ne souhaitant pas être reconnaissables ?
11. Faut-il autoriser les reconstructions plausibles, ou seulement les scènes directement attestées dans le premier pilote ?
12. Export prioritaire après PDF : EPUB fixe ou CBZ ?

Orientation recommandée pour démarrer vite :

- chapitre fictif ;
- 8 pages ;
- roman graphique semi-réaliste ;
- mode manuel ChatGPT ;
- validation à trois jalons ;
- projet JSON + dossier d’images ;
- PDF uniquement.
