# Questions de comparaison (F5)

Le CDC demande 30 à 50 questions par bibliothèque : français, anglais, sigles courts, auteurs,
phrases exactes, filtres. Elles servent au banc de comparaison (BAS-03), qui les pose **à
l'identique** aux deux bibliothèques et compare les réponses.

Un fichier par bibliothèque, une question par ligne, les lignes vides et celles qui commencent
par `#` ignorées. Les questions d'une bibliothèque portent nécessairement son vocabulaire : ce
sont des **données**, et elles vivent ici pour cette raison (CLA-01).

Le jeu réel de la bibliothèque à reprendre se constituera au début du lot E3, à partir des
recherches qui comptent pour celle qui s'en sert — pas à partir de ce qu'on imagine qu'elle
cherche. `essai.txt` ne sert qu'à éprouver le banc lui-même.
