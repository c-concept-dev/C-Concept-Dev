# Checklist — dossier de location en France pour un salarié en CDI

> Le bailleur ou l’agence ne peut demander que les justificatifs prévus par la réglementation. Les pièces exactes varient selon le logement et votre situation.

## 1. Préparer les pièces du locataire

### Identité
- [ ] Une pièce d’identité en cours de validité :
  - carte nationale d’identité ;
  - passeport ;
  - permis de conduire ;
  - titre de séjour, le cas échéant.

### Domicile actuel
Un justificatif parmi les suivants :
- [ ] Trois dernières quittances de loyer ;
- [ ] Attestation du précédent bailleur indiquant que loyers et charges sont à jour ;
- [ ] Attestation d’hébergement signée + justificatif de domicile de l’hébergeant ;
- [ ] Attestation d’élection de domicile ;
- [ ] Dernier avis de taxe foncière ou titre de propriété si vous êtes propriétaire.

### Situation professionnelle en CDI
- [ ] Contrat de travail signé ;  
**ou**
- [ ] Attestation récente de l’employeur précisant idéalement :
  - l’emploi occupé ;
  - la rémunération ;
  - la date d’entrée ;
  - le type de contrat ;
  - si la période d’essai est terminée.

### Revenus
- [ ] Trois derniers bulletins de salaire ;
- [ ] Dernier ou avant-dernier avis d’imposition ;
- [ ] Justificatifs d’éventuels revenus complémentaires réguliers :
  - primes contractuelles ;
  - pensions ;
  - allocations ;
  - revenus fonciers ;
  - revenus de placements, si pertinents.

### Documents facultatifs pouvant faciliter l’examen
- [ ] Courte page de présentation avec coordonnées, emploi, revenus nets et date d’emménagement souhaitée ;
- [ ] Simulation ou attestation **Visale**, si vous êtes éligible ;
- [ ] Justificatifs d’épargne uniquement si vous souhaitez volontairement renforcer votre dossier.

## 2. Si une caution personnelle est demandée

Préparer pour le garant :

- [ ] Pièce d’identité ;
- [ ] Justificatif de domicile ;
- [ ] Justificatif de situation professionnelle ;
- [ ] Trois derniers bulletins de salaire ou autres justificatifs de ressources ;
- [ ] Dernier ou avant-dernier avis d’imposition ;
- [ ] Acte de cautionnement, à signer au moment requis.

Alternative :
- [ ] Demander un visa **Visale** avant la signature du bail, lorsque vous êtes éligible.

> Lorsque le bailleur dispose déjà d’une assurance contre les loyers impayés, il ne peut généralement pas demander en plus une caution personnelle, sauf notamment pour certains étudiants ou apprentis.

## 3. Mettre le dossier en forme

- [ ] Scanner les pièces de façon lisible, de préférence en PDF ;
- [ ] Donner des noms clairs aux fichiers : `01_Identite.pdf`, `02_Contrat_CDI.pdf`, etc. ;
- [ ] Regrouper les documents dans un seul dossier ou PDF ordonné ;
- [ ] Ajouter un filigrane, par exemple :  
  **« Document transmis uniquement pour la location du logement [adresse] – [date] »** ;
- [ ] Ne jamais modifier les montants ou informations figurant sur les justificatifs ;
- [ ] Conserver les originaux et ne transmettre que des copies ;
- [ ] Utiliser si possible le service public gratuit **DossierFacile**, qui vérifie et sécurise le dossier.

## 4. Déroulement de la candidature

### Avant de transmettre les documents
- [ ] Vérifier l’identité et les coordonnées de l’agence ou du bailleur ;
- [ ] Visiter le logement, physiquement ou par visioconférence fiable ;
- [ ] Vérifier l’adresse, le montant du loyer, les charges, la surface et le type de bail ;
- [ ] Éviter d’envoyer des pièces sensibles à une personne non identifiée ;
- [ ] Ne verser aucune somme pour « réserver » le logement avant la signature régulière du bail.

### Dépôt et étude du dossier
- [ ] Envoyer le dossier complet par un canal sécurisé ;
- [ ] Demander confirmation de sa réception ;
- [ ] Répondre rapidement aux demandes de pièces complémentaires autorisées ;
- [ ] Vérifier les conditions financières : loyer, charges, dépôt de garantie et frais d’agence.

### Après acceptation
- [ ] Lire intégralement le contrat de location ;
- [ ] Contrôler les diagnostics et annexes remis par le bailleur ;
- [ ] Souscrire une assurance habitation avant la remise des clés ;
- [ ] Signer le bail et conserver un exemplaire ;
- [ ] Régler les sommes prévues au moment convenu :
  - premier loyer ;
  - dépôt de garantie ;
  - éventuels frais d’agence réglementés ;
- [ ] Effectuer un état des lieux d’entrée détaillé, avec photos ;
- [ ] Relever les compteurs et récupérer toutes les clés.

## 5. Repères financiers

- **Location vide** : dépôt de garantie limité à **un mois de loyer hors charges**.
- **Location meublée constituant la résidence principale** : dépôt limité à **deux mois de loyer hors charges**.
- Les frais d’agence imputables au locataire sont plafonnés selon la zone et la surface.
- Il est prudent de ne pas envoyer d’argent avant d’avoir vérifié le logement, l’interlocuteur et le bail.

## 6. Documents à ne pas communiquer normalement

Un bailleur ne doit notamment pas exiger :

- [ ] Relevés complets de compte bancaire ;
- [ ] Carte Vitale ou dossier médical ;
- [ ] Extrait de casier judiciaire ;
- [ ] Dossier médical ;
- [ ] Autorisation de prélèvement automatique imposée avant le bail ;
- [ ] Somme d’argent destinée à « bloquer » ou réserver le logement hors cadre légal ;
- [ ] Documents sans lien avec les catégories de justificatifs autorisées.

**Base pratique recommandée pour un CDI :** pièce d’identité + trois quittances de loyer + contrat ou attestation employeur + trois bulletins de salaire + avis d’imposition + dossier du garant ou visa Visale.
