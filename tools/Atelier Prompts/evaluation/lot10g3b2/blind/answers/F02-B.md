# Checklist chronologique — déménagement dans 6 semaines

**Contexte :** appartement de 60 m², déménagement dans la même ville, sur un week-end.

## Cette semaine — J-6 semaines : cadrage et réservations

### Organisation
- [ ] Fixer le week-end et les horaires précis du déménagement.
- [ ] Choisir entre :
  - [ ] déménageurs professionnels ;
  - [ ] location d’un utilitaire avec aide de proches.
- [ ] Estimer le volume à transporter — généralement **25 à 35 m³** pour 60 m², selon l’ameublement.
- [ ] Établir un budget : véhicule ou déménageur, cartons, stationnement, ménage, repas, éventuelle garde d’enfants ou d’animaux.
- [ ] Demander 3 devis ou réserver un utilitaire adapté.
- [ ] Vérifier les conditions d’accès aux deux logements : étage, ascenseur, largeur des portes, cour, digicode, distance de portage.
- [ ] Confirmer les règles d’utilisation de l’ascenseur auprès des copropriétés.
- [ ] Demander à la mairie les autorisations de stationnement aux deux adresses.
- [ ] Réserver de l’aide : idéalement **3 à 5 personnes** si vous déménagez sans professionnels.

### Logement
- [ ] Envoyer le préavis à l’ancien propriétaire si ce n’est pas déjà fait.
- [ ] Fixer l’état des lieux de sortie et la remise des clés.
- [ ] Fixer la récupération des clés du nouveau logement, si possible avant le week-end.
- [ ] Vérifier que votre assurance couvre le déménagement et le nouveau logement.

---

## J-5 semaines : tri et matériel

- [ ] Trier chaque pièce : **garder / vendre / donner / jeter**.
- [ ] Mettre rapidement en vente les meubles et objets non conservés.
- [ ] Organiser les dons et le passage en déchèterie.
- [ ] Mesurer les meubles volumineux et les accès du nouveau logement.
- [ ] Préparer un plan simple de destination des meubles.
- [ ] Acheter ou récupérer environ :
  - [ ] **40 à 60 cartons standards** ;
  - [ ] 10 à 15 petits cartons pour les livres ;
  - [ ] papier bulle ou papier d’emballage ;
  - [ ] ruban adhésif et dévidoir ;
  - [ ] marqueurs et étiquettes ;
  - [ ] housses ou couvertures de protection ;
  - [ ] sacs solides, film étirable et sachets pour la visserie.
- [ ] Créer une couleur par pièce : cuisine, salon, chambre, salle de bains, etc.

---

## J-4 semaines : démarches et premiers cartons

### Emballage
- [ ] Commencer par les objets peu utilisés : livres, décoration, archives, vêtements hors saison.
- [ ] Numéroter chaque carton.
- [ ] Inscrire sur deux côtés :
  - [ ] la pièce de destination ;
  - [ ] le contenu ;
  - [ ] « fragile » si nécessaire.
- [ ] Tenir une liste sommaire des cartons numérotés.
- [ ] Photographier les objets de valeur avant emballage.

### Démarches
- [ ] Souscrire l’assurance habitation du nouveau logement à compter de la remise des clés.
- [ ] Programmer le transfert ou l’ouverture de l’électricité et du gaz.
- [ ] Programmer le transfert d’internet ; vérifier si un rendez-vous technique est nécessaire.
- [ ] Signaler progressivement le changement d’adresse : banque, employeur, assurances, organismes sociaux, abonnements.
- [ ] Prévoir la réexpédition du courrier si utile.

---

## J-3 semaines : logistique détaillée

- [ ] Confirmer le véhicule ou le déménageur par écrit.
- [ ] Vérifier les horaires autorisés, particulièrement si le déménagement a lieu le dimanche.
- [ ] Confirmer les autorisations de stationnement et la pose éventuelle de panneaux.
- [ ] Prévoir le matériel de manutention :
  - [ ] diable ;
  - [ ] chariot ;
  - [ ] sangles ;
  - [ ] couvertures ;
  - [ ] gants ;
  - [ ] tendeurs.
- [ ] Organiser la garde des enfants ou animaux.
- [ ] Prévoir les repas, boissons et collations du week-end.
- [ ] Commencer à vider cave, balcon, garage ou débarras.
- [ ] Consommer les réserves du congélateur et les produits alimentaires ouverts.
- [ ] Repérer les meubles à démonter et vérifier que vous avez les bons outils.

---

## J-2 semaines : accélération de l’emballage

- [ ] Emballer la majorité de la vaisselle, du linge et des vêtements.
- [ ] Laisser seulement le nécessaire pour deux semaines.
- [ ] Sauvegarder les données importantes des ordinateurs.
- [ ] Photographier les branchements électroniques avant de débrancher.
- [ ] Mettre câbles et accessoires dans des sachets étiquetés.
- [ ] Préparer un dossier à garder avec vous :
  - [ ] pièces d’identité ;
  - [ ] contrats et états des lieux ;
  - [ ] assurances ;
  - [ ] réservations ;
  - [ ] clés ;
  - [ ] ordonnances et médicaments.
- [ ] Confirmer l’heure d’arrivée de tous les participants.
- [ ] Envoyer à chacun les adresses, digicodes, consignes de stationnement et numéro de téléphone.
- [ ] Prévoir le ménage de sortie : vous-même ou prestataire.

---

## Dernière semaine

### Du lundi au mercredi
- [ ] Terminer les cartons, sauf les produits indispensables.
- [ ] Démonter les meubles non utilisés.
- [ ] Mettre la visserie de chaque meuble dans un sachet identifié, fixé au meuble ou conservé dans une boîte dédiée.
- [ ] Dégivrer et nettoyer le congélateur selon le délai recommandé.
- [ ] Vider progressivement le réfrigérateur.
- [ ] Laver et sécher le linge restant.
- [ ] Préparer les protections pour matelas, canapé, miroirs et écrans.
- [ ] Vérifier une dernière fois les accès et le stationnement.

### Jeudi
- [ ] Confirmer le véhicule, les déménageurs et les proches.
- [ ] Charger les téléphones et batteries externes.
- [ ] Retirer de l’argent si des frais doivent être réglés sur place.
- [ ] Préparer une caisse à outils : tournevis, clés Allen, cutter, ruban adhésif, pinces, marteau.
- [ ] Préparer les produits de ménage séparément.

### Vendredi
- [ ] Faire les derniers cartons.
- [ ] Démonter les derniers meubles, sauf le lit si nécessaire.
- [ ] Préparer une **valise pour 48 heures** :
  - [ ] vêtements ;
  - [ ] trousse de toilette ;
  - [ ] médicaments ;
  - [ ] chargeurs ;
  - [ ] serviettes et draps ;
  - [ ] papier toilette ;
  - [ ] café, eau et encas.
- [ ] Préparer un **carton “première nuit”** : vaisselle minimale, savon, sacs-poubelle, essuie-tout, ampoules, outils, produits de nettoyage.
- [ ] Regrouper cartons et meubles près de la sortie sans bloquer les passages.
- [ ] Garder séparément papiers, clés, bijoux, ordinateur et objets de valeur.
- [ ] Faire le plein du véhicule si vous le louez.

---

# Week-end du déménagement

## Samedi matin — chargement

- [ ] Prendre des photos de l’état de l’ancien logement.
- [ ] Protéger les sols, portes, angles et parties communes.
- [ ] Vérifier que l’ascenseur et les places de stationnement sont disponibles.
- [ ] Attribuer les rôles : chargement, transport, accueil au nouveau logement.
- [ ] Charger dans cet ordre :
  1. [ ] meubles lourds et démontés ;
  2. [ ] électroménager ;
  3. [ ] cartons lourds ;
  4. [ ] cartons légers et fragiles ;
  5. [ ] matériel nécessaire à l’arrivée.
- [ ] Maintenir réfrigérateur et appareils debout autant que possible.
- [ ] Ne pas surcharger les cartons : environ **15 à 20 kg maximum**.
- [ ] Faire une dernière inspection des placards, cave, balcon et compteurs.

## Samedi après-midi — déchargement

- [ ] Photographier le nouveau logement avant installation, notamment les éventuels défauts.
- [ ] Protéger les sols et les passages.
- [ ] Diriger immédiatement chaque carton vers sa pièce.
- [ ] Installer en priorité :
  - [ ] lits ;
  - [ ] réfrigérateur ;
  - [ ] éclairage ;
  - [ ] table et chaises ;
  - [ ] nécessaire de salle de bains.
- [ ] Vérifier l’eau chaude, l’électricité, le chauffage et les sanitaires.
- [ ] Contrôler rapidement les meubles et objets fragiles.
- [ ] Signaler immédiatement les dommages au déménageur, le cas échéant.

## Dimanche — installation et ancien logement

- [ ] Finir le montage des meubles essentiels.
- [ ] Déballer la cuisine, la salle de bains et les vêtements utiles.
- [ ] Nettoyer l’ancien logement.
- [ ] Reboucher les petits trous si le bail et l’état du logement le nécessitent.
- [ ] Retirer tous les déchets et derniers objets.
- [ ] Relever et photographier les compteurs.
- [ ] Réaliser l’état des lieux et rendre toutes les clés, si prévu.
- [ ] Rapporter l’utilitaire avec le niveau de carburant demandé.
- [ ] Conserver les justificatifs de location, de carburant et de déménagement.

---

## Semaine suivant le déménagement

- [ ] Tester l’électroménager et vérifier qu’aucun objet n’a été endommagé.
- [ ] Signaler rapidement les dommages ou réserves au déménageur selon les délais contractuels.
- [ ] Finaliser les changements d’adresse.
- [ ] Mettre à jour l’adresse sur la carte grise dans le délai légal applicable.
- [ ] Vérifier la clôture ou le transfert des anciens contrats.
- [ ] Inscrire votre nom sur la boîte aux lettres et l’interphone.
- [ ] Rendre ou recycler les cartons.
- [ ] Vérifier le remboursement du dépôt de garantie après l’état des lieux.
- [ ] Conserver factures, états des lieux et photos dans un même dossier.
