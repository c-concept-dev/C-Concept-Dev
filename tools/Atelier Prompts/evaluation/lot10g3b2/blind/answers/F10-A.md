Voici un plan d’analyse concret pour identifier **les trois principaux irritants clients** et leurs **différences par segment**.

## 1. Définir ce qu’est un « irritant principal »

Un irritant peut être classé selon trois dimensions :

- **Fréquence** : proportion de clients qui le rencontrent ;
- **Sévérité** : niveau de gêne ou d’insatisfaction ;
- **Impact** : lien avec la satisfaction globale, le NPS, l’intention de rachat ou le risque de départ.

Idéalement, le classement final ne repose pas uniquement sur le nombre de mentions. Par exemple :

\[
Score\ d’irritant = Fréquence \times Sévérité \times Impact
\]

Si le questionnaire ne mesure pas ces trois dimensions, utilisez les variables disponibles et documentez la méthode.

---

## 2. Inventorier le fichier CSV

Identifier les colonnes correspondant à :

- l’identifiant du répondant ;
- la date de réponse ;
- la satisfaction globale ou le NPS ;
- les questions portant sur les problèmes rencontrés ;
- leur importance ou leur gravité ;
- les commentaires libres ;
- les variables de segmentation :
  - type de client ;
  - produit ou offre ;
  - canal ;
  - ancienneté ;
  - région ;
  - tranche d’âge ;
  - valeur ou niveau de dépense.

Créer un dictionnaire des variables avec :

| Colonne | Signification | Type | Valeurs possibles |
|---|---|---|---|
| `nps` | Recommandation | Numérique | 0–10 |
| `segment` | Type de client | Catégorielle | Particulier, PME… |
| `probleme_livraison` | Irritant livraison | Binaire | Oui/Non |

---

## 3. Contrôler et nettoyer les données

### Contrôles principaux

- doublons de répondants ;
- réponses incomplètes ;
- valeurs impossibles ou hors échelle ;
- catégories écrites différemment ;
- encodage des caractères et séparateur du CSV ;
- dates incohérentes ;
- segments avec très peu de répondants.

### Traitement des valeurs manquantes

Distinguer :

- « non concerné » ;
- « ne sait pas » ;
- question non affichée ;
- absence réelle de réponse.

Ne pas assimiler automatiquement une absence de réponse à l’absence d’irritant.

### Taille minimale des segments

Éviter des conclusions fermes pour les petits groupes. À titre pratique :

- `n < 30` : résultats exploratoires ;
- `n ≥ 30` : comparaisons possibles avec prudence ;
- afficher systématiquement l’effectif de chaque segment.

---

## 4. Harmoniser les irritants

### Questions fermées

Transformer les réponses dans un format commun, par exemple :

| Répondant | Irritant | Présent | Sévérité |
|---|---|---:|---:|
| 001 | Livraison lente | 1 | 4 |
| 001 | Support difficile à joindre | 1 | 5 |
| 002 | Livraison lente | 0 | — |

Ramener si nécessaire les échelles sur une base commune, par exemple de 0 à 100.

### Commentaires libres

Mettre en place un codage thématique :

1. nettoyer les textes sans supprimer les négations ;
2. définir une taxonomie initiale : livraison, prix, support, ergonomie, facturation, qualité produit, etc. ;
3. attribuer un ou plusieurs thèmes à chaque commentaire ;
4. regrouper les synonymes ;
5. contrôler manuellement un échantillon ;
6. ajouter les thèmes émergents absents des questions fermées.

Pour fiabiliser le résultat, faire coder un échantillon par deux personnes ou vérifier manuellement les catégories produites par un modèle d’IA.

---

## 5. Calculer les indicateurs par irritant

Pour chaque irritant, calculer :

### Fréquence

\[
Fréquence = \frac{\text{Nombre de répondants concernés}}{\text{Nombre de répondants éligibles}}
\]

### Sévérité

- moyenne et médiane ;
- proportion de notes élevées, par exemple 4–5 sur une échelle de 1 à 5.

### Impact client

Comparer la satisfaction ou le NPS entre :

- les clients ayant rencontré l’irritant ;
- ceux ne l’ayant pas rencontré.

Exemple :

\[
Impact\ satisfaction =
Satisfaction_{sans\ irritant} - Satisfaction_{avec\ irritant}
\]

Une régression peut compléter cette analyse pour isoler l’effet de chaque irritant en tenant compte des autres variables.

### Incertitude

Ajouter :

- intervalles de confiance ;
- effectifs ;
- tests statistiques lorsque pertinents.

---

## 6. Déterminer les trois irritants principaux

Construire un tableau de priorité :

| Irritant | Fréquence | Sévérité | Baisse de satisfaction | Score de priorité |
|---|---:|---:|---:|---:|
| Support difficile à joindre | 31 % | 4,4/5 | −18 pts | 82 |
| Retard de livraison | 38 % | 3,8/5 | −12 pts | 75 |
| Facture peu claire | 22 % | 4,2/5 | −15 pts | 68 |

Une formule possible, après normalisation de chaque composante entre 0 et 100 :

- 40 % fréquence ;
- 30 % sévérité ;
- 30 % impact.

Effectuer aussi une **analyse de sensibilité** : vérifier si le top 3 reste stable avec d’autres pondérations. S’il change fortement, présenter plusieurs angles plutôt qu’un classement artificiellement précis.

---

## 7. Analyser les différences par segment

Pour chaque segment prioritaire, calculer :

- fréquence de chaque irritant ;
- sévérité moyenne ;
- impact sur satisfaction ou NPS ;
- écart par rapport à l’ensemble.

Exemple :

| Segment | Irritant | Fréquence segment | Fréquence globale | Écart |
|---|---|---:|---:|---:|
| Nouveaux clients | Support | 45 % | 31 % | +14 pts |
| Clients historiques | Support | 24 % | 31 % | −7 pts |

### Tests recommandés

- **Chi-deux** ou test exact de Fisher pour les fréquences ;
- **test t**, ANOVA ou alternatives non paramétriques pour les scores ;
- régression logistique pour la présence d’un irritant ;
- régression linéaire ou ordinale pour la satisfaction.

Corriger les comparaisons multiples si de nombreux segments sont testés, par exemple avec la méthode de Benjamini-Hochberg.

Une différence doit être considérée comme importante si elle est à la fois :

- statistiquement crédible ;
- suffisamment grande pour être utile opérationnellement ;
- fondée sur un effectif raisonnable.

---

## 8. Vérifier les biais

Contrôler notamment :

- la représentativité de l’échantillon ;
- la surreprésentation de certains segments ;
- les différences de taux de réponse ;
- les effets liés au canal ou à la période ;
- l’ordre des questions ;
- le biais de non-réponse ;
- l’effet de clients ayant plusieurs irritants simultanément.

Si des données de population sont disponibles, appliquer des pondérations par segment et présenter les résultats pondérés et non pondérés.

---

## 9. Restitution recommandée

### Synthèse exécutive

Pour chacun des trois irritants :

1. part des clients concernés ;
2. niveau de sévérité ;
3. impact sur satisfaction ou fidélité ;
4. segments les plus touchés ;
5. verbatims représentatifs ;
6. action recommandée.

### Visualisations

- graphique en barres du top 10 des irritants ;
- matrice **fréquence × impact** ;
- heatmap irritants × segments ;
- barres avec intervalles de confiance ;
- verbatims illustratifs anonymisés.

### Forme de conclusion

> **Irritant 1 — Support difficile à joindre**  
> Concerne 31 % des répondants et 45 % des nouveaux clients. Il est associé à une baisse de 18 points de satisfaction. L’écart du segment « nouveaux clients » est élevé et statistiquement crédible. Priorité : réduire le délai de première réponse.

---

## 10. Livrables finaux

- fichier nettoyé ;
- dictionnaire des variables ;
- table des irritants normalisée ;
- classement global et par segment ;
- résultats des tests statistiques ;
- visualisations ;
- synthèse d’une page ;
- annexe méthodologique précisant les pondérations, exclusions et limites.

Pour adapter précisément ce plan, les informations les plus utiles sont la **liste des colonnes**, les **échelles de réponse**, les **variables de segmentation** et la présence éventuelle de **commentaires libres**.
