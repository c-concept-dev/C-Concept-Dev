# Signaux universels de préparation

Les signaux décrivent une opération cognitive préalable, pas un secteur.

| Signal | Sens |
|---|---|
| strategy_design | une stratégie doit être conçue avant production |
| dependent_components | plusieurs composants/étapes dépendants doivent être coordonnés |
| constraint_arbitration | des contraintes en tension nécessitent un arbitrage |
| linked_scenarios | plusieurs scénarios liés doivent être construits/comparés |
| architecture_coordination | une architecture ou organisation de composants doit être conçue |
| research_planning | une recherche structurante doit être planifiée avant synthèse |

Une liste, un tableau, une quantité, un format ou plusieurs sections ne constituent pas à eux seuls un signal.
