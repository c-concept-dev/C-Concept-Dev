# Mapping des cinq propriétés vers ADN State

| Propriété | Bloc runtime | Preuve |
|---|---|---|
| Intentionalité | `intent` | demande conservée, statut d'intention, contraintes explicites |
| Exécutabilité | `executability` | état, confiance, manques, clarification |
| Discipline | `discipline` | `execute_now`, interdiction questions de confort, injonction finale |
| Complétude | `completeness` | obligations, quantités, couverture |
| Conformité | `compliance` | output + checks + disponibilité des contrôles |

Les valeurs synthétiques dans `properties` sont calculées par dérivation pure et contrôlées par `validateAdnState()`.
